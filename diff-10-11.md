# Pong: from `pong-10` to `pong-11` — "The Audio Update"

## 1. General task description

`pong-10` is a complete game, but silent.

In `pong-11` we add **sound effects**:

- a "blip" when the ball hits a **paddle**;
- a different sound when it hits the **top or bottom wall**;
- a sound when someone **scores**.

The sound files are ready-made assets — we only include them. We also set the winning score to the real value, **10**.

### Files

| File | What happens |
|---|---|
| `sounds/paddle_hit.wav` | **New.** Ready-made sound asset — copy it in, don't create it |
| `sounds/wall_hit.wav` | **New.** Ready-made sound asset — copy it in |
| `sounds/score.wav` | **New.** Ready-made sound asset — copy it in |
| `main.lua` | Edited |

| `class.lua`, `push.lua`, `font.ttf` | Third-party, unchanged |

## 2. Steps from `pong-10` to `pong-11`

### Step 1. Add the sound files

Create a folder named `sounds` in the project and copy the three `.wav` files into it:

```
sounds/
  paddle_hit.wav
  score.wav
  wall_hit.wav
```

### Step 2. Update the header comment

```lua
    pong-11
    "The Audio Update"
```

### Step 3. Load the sounds in `love.load()`

After the fonts are created:

```lua
    sounds = {
        ['paddle_hit'] = love.audio.newSource('sounds/paddle_hit.wav', 'static'),
        ['score'] = love.audio.newSource('sounds/score.wav', 'static'),
        ['wall_hit'] = love.audio.newSource('sounds/wall_hit.wav', 'static')
    }
```

> - `sounds` is a Lua **table** used like a dictionary: we look up each sound by name.
> - `'static'` loads the whole sound into memory once — best for short effects that play often. (Long music would use `'stream'`.)

### Step 4. Play a sound on paddle hits

In `love.update(dt)`, at the end of **each** paddle collision block (`if ball:collides(player1)` and `if ball:collides(player2)`), add:

```lua
            sounds['paddle_hit']:play()
```

### Step 5. Play a sound on wall hits

In **both** wall checks (top and bottom), after `ball.dy = -ball.dy`:

```lua
            sounds['wall_hit']:play()
```

### Step 6. Play a sound when someone scores

In **both** edge checks, right after the score is increased (`player2Score = player2Score + 1` and `player1Score = player1Score + 1`):

```lua
            sounds['score']:play()
```

### Step 7. Set the winning score to 10

In both edge checks, change the test from `== 2` to:

```lua
            if player2Score == 10 then
```

```lua
            if player1Score == 10 then
```

### Step 8. (Optional) FPS color

The repo writes the green back as `love.graphics.setColor(0, 255/255, 0, 255/255)` — the same color as before.

### Step 9. Run and check

Run `love .` and play with sound on. You should hear different sounds for paddle hits, wall bounces and points. The game now ends at 10 points.
